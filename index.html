      SFTS 예방수칙

      아직 예방 백신이 없어서 진드기에 물리지 않는 것이 가장 중요합니다.

      • 긴 옷 입기밭일·성묘·등산 때 긴팔, 긴바지, 모자, 장갑, 장화를 착용하세요.
      • 기피제 사용진드기 기피제를 옷과 드러난 피부에 뿌리세요.
      • 풀밭에 바로 앉지 않기돗자리를 쓰고, 옷을 풀밭에 벗어 두지 마세요. 쓴 돗자리는 털어서 씻어 두세요.
      • 정해진 길로 다니기등산로나 산책로를 벗어나 풀숲에 들어가지 마세요.
      • 집에 오면 바로 씻고 세탁머리카락, 귀 주변, 겨드랑이, 허리, 무릎 뒤에 진드기가 붙어 있는지 살펴보세요.
      • 2주 안에 열이 나면 병원야외활동 뒤 2주 안에 고열, 구토, 설사가 있으면 병원에 가서 야외활동 사실을 알리세요. 물린 진드기는 억지로 떼지 마세요.

      질병관리청 진드기 매개 감염병 예방 안내를 바탕으로 요약했습니다. 실서비스에서는 최신 공식 문구로 맞춥니다. 문의: 질병관리청 콜센터 1339

      제안 구조

      수집·예측 코드는 그대로 두고, 결과를 하루 한 번 미리 계산해 가벼운 파일로 내보냅니다. 화면은 계산을 기다리지 않고 파일만 읽어서 바로 뜹니다.

      1. 기존 그대로기상청 자료 수집지금 돌아가는 자동 수집 코드
      2. 기존 그대로GBM 예측을 하루 1회 미리 계산매일 새벽 자동 실행 (서버 예약 작업 또는 GitHub Actions)
      3. 이번 작업JSON 파일로 저장오늘 단계·14일 예측·읍면동 값. 수 KB 크기
      4. 이번 작업CDN 정적 웹이 화면. 서버 계산 없이 가까운 CDN에서 바로 전달

      A안 · 정적 웹 + JSON 추천

      • 화면과 데이터를 CDN이 바로 전달해서 서버 대기가 없습니다.
      • 무료 호스팅 범위 안에서 운영할 수 있습니다.
      • 서버가 없어서 잠들거나 멈출 걱정이 없습니다.
      • 한계: 하루 1회 갱신(횟수는 늘릴 수 있음). 화면에서 조건을 바꿔 새로 계산하는 기능은 맞지 않습니다.

      B안 · FastAPI

      • 같은 JSON을 API로 내려주고, 화면은 그대로 씁니다.
      • 로그인, 기관별 화면, 조건을 바꿔 다시 계산하기가 필요할 때 맞습니다.
      • 서버 운영비와 관리가 필요합니다.
      • A안으로 시작해도 나중에 B안으로 넓힐 수 있습니다.
